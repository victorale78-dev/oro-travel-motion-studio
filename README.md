# Oro Travel Motion Studio

Proyecto de reels turísticos en **Remotion** para Oro Travel.

## Requisitos
- Node.js 20+
- npm

## Instalar
```bash
npm install
```

## Vista previa
```bash
npm start
```

## Exportar MP4
```bash
npm run render
```

El video es vertical **1080 × 1920**, **30 fps**, **30 segundos**.

### Recursos pendientes
Colocá las fotografías con estos nombres en `public/images/`:
- `granada.jpg`
- `ometepe.jpg`
- `corn-islands.jpg`
- `san-juan.jpg`

Las transiciones, movimientos de cámara y títulos están implementados como base. **Los subtítulos sincronizados, la voz ElevenLabs, música y tipografías corporativas finales todavía no están integrados.** El proyecto no ha sido renderizado ni probado en CI.

### Privacidad
El repositorio actual está configurado como **público** en GitHub. Cambialo en Settings > General > Danger Zone > Change repository visibility si querés mantener el trabajo privado.
